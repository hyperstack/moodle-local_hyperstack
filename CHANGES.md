# Changes

## 1.0.0 (2026-10-24)

First release.

- Connect a Moodle site to Hyperstack with an API key (stored encrypted) and test the connection.
- Choose a course's credential groups under More → Hyperstack credentials.
- Issue a credential when a learner completes the course, in a background task with retries.
- Issue to learners who completed the course before.
- Course report with status, credential link and retry.
- Privacy API, backup and restore of course credential groups.
